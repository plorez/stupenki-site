# Сайт «Ступеньки»: приём заказов в Telegram

Что внутри:
- `public/index.html` — сайт (дизайн и корзина как раньше).
- `netlify/functions/order.js` — «почтальон»: получает заказ с сайта, проверяет и отправляет в Telegram.
- `netlify/functions/menu.json` — меню для проверки цен (создаётся само из сайта).
- `netlify.toml` — настройки для Netlify.

Секретов (токена бота) в файлах нет. Вы введёте их один раз в настройках Netlify.


## Важно: сайт на GitHub Pages и приём заказов
GitHub Pages показывает только страницу и **не выполняет серверный код**, поэтому заказы через него не уйдут. Нужен сайт на Netlify (шаги 3–6 ниже, но на Netlify подключается тот же репозиторий). После этого:
1. В `index.html` найдите строку `const NETLIFY_SITE='';` и впишите адрес Netlify-сайта, например `const NETLIFY_SITE='https://stupenki.netlify.app';`.
2. В Netlify (Environment variables) при необходимости задайте `ALLOWED_ORIGINS`: адреса сайтов, с которых разрешено отправлять заказы. По умолчанию разрешён `https://plorez.github.io`. Через несколько секунд после сохранения нужен повторный деплой.
3. Пока адрес не вписан, кнопка «Отправить заказ» честно сообщает, что сервер не подключён, а «Скопировать заказ» работает.

## Что нужно сделать вам (6 шагов)

### Шаг 1. Создайте Telegram-бота (3 минуты)
1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите «Запустить».
2. Отправьте `/newbot`. Придумайте название (например, «Ступеньки заказы») и имя бота, которое заканчивается на `bot` (например, `stupenki_orders_bot`).
3. BotFather пришлёт **токен**: длинная строка с цифрами и двоеточием. Это пароль бота. Никому не показывайте и не вставляйте в чаты, в том числе мне.
4. Найдите своего нового бота по имени и нажмите **«Запустить»** (Start). Без этого он не сможет вам писать.

### Шаг 2. Узнайте свой chat id
1. Найдите в Telegram бота **@userinfobot** и нажмите «Запустить».
2. Он пришлёт ваш **Id** (число). Это адрес, куда бот будет присылать заказы.

Позже, когда кофейня согласится, заказы можно направить в её чат: придётся узнать id того чата и поменять значение в Шаге 5.

### Шаг 3. Загрузите проект на GitHub
Netlify лучше всего работает с GitHub.
1. Зарегистрируйтесь на github.com.
2. Нажмите **New repository**, назовите `stupenki-site`, выберите **Private**, создайте.
3. Распакуйте архив `stupenki-site.zip`. В репозитории нажмите **Add file → Upload files** и перетащите **содержимое** папки (папки `public`, `netlify`, `scripts`, `test` и файлы `netlify.toml`, `package.json`, `README.md`). Нажмите **Commit changes**.

### Шаг 4. Подключите Netlify
1. Зарегистрируйтесь на netlify.com (можно через GitHub).
2. **Add new site → Import an existing project → GitHub**, выберите `stupenki-site`.
3. Ничего не меняйте (настройки подтянутся из `netlify.toml`) и нажмите **Deploy**.

### Шаг 5. Введите секреты в Netlify
1. Откройте сайт в Netlify → **Site configuration → Environment variables → Add a variable**.
2. Добавьте три переменные (названия копируйте точно):
   - `TELEGRAM_BOT_TOKEN` — токен из Шага 1.
   - `TELEGRAM_CHAT_ID` — число из Шага 2.
   - `ORDER_MODE` — значение `test`.
3. Откройте **Deploys → Trigger deploy → Deploy site**. Это нужно, чтобы настройки заработали.

### Шаг 6. Отправьте тестовый заказ
1. Откройте адрес вашего сайта на Netlify (вида `что-то.netlify.app`), добавьте напиток в корзину, заполните форму и нажмите «Отправить заказ».
2. На сайте появится «Тестовый заказ № … отправлен», а в Telegram придёт сообщение с пометкой 🧪 ТЕСТОВЫЙ ЗАКАЗ.

## Если что-то не работает
- **На сайте «Не удалось отправить заказ», в Telegram пусто.** Проверьте, что нажали «Запустить» у своего бота, что значения в Шаге 5 без пробелов и что после ввода сделали повторный деплой.
- **Ошибка в Netlify.** Откройте **Logs → Functions → order**: там написана причина (токен не задан, Telegram отклонил запрос и т.д.). Токен в логи не попадает.
- **Если токен попал в чужие руки:** в @BotFather отправьте `/revoke`, получите новый и замените в Netlify.

## Когда кофейня согласится
1. Поменяйте `ORDER_MODE` на `live` и сделайте повторный деплой: пометка «ТЕСТ» исчезнет, а гостям покажут «Заказ принят».
2. Договоритесь с кофейней о способах получения, времени работы и том, кто смотрит Telegram.
3. Добавьте на сайт согласие на обработку персональных данных (имя и телефон) и политику конфиденциальности. Требования зависят от закона страны, лучше уточнить у юриста.

## Если меняете меню или цены
Правьте блок `const D=` в `public/index.html`. При каждом деплое Netlify сам обновит `menu.json`.

## Что пока не защищено
Нет ограничения на число заказов с одного адреса: от автоматических ботов защищает только скрытое поле-ловушка. Если появятся поддельные заказы, добавим капчу или лимиты.
